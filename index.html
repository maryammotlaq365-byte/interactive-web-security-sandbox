ABOUT THE PROJECT

Security Through Practice

Web Security Sandbox is an educational project designed to help beginners understand web vulnerabilities through safe browser-based simulations.

Each lab demonstrates a vulnerable scenario, explains its impact, and shows how the same scenario behaves after applying a security fix.
