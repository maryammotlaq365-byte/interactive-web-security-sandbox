Clickjacking

Learn how attackers trick users into clicking hidden elements on a website without their knowledge.

01. What is Clickjacking?

Clickjacking is a UI redressing attack where an attacker tricks a user into clicking an invisible or disguised element, causing an unintended action.

OWASP: A05:2021 – Security Misconfiguration

CWE: CWE-1021 – Improper Restriction of Rendered UI Layers or Frames

03. Vulnerable Code

The vulnerable website does not restrict other websites from embedding it inside an iframe. 

<!-- Vulnerable server response -->
HTTP/1.1 200 OK
Content-Type: text/html

<html>
  <body>
    <button>Confirm Account Action</button>
  </body>
</html>

Vulnerable point: The response has no frame protection policy, so another website may embed the page in a frame.

04. The Fix

The server should prevent unauthorized websites from embedding sensitive pages. 

HTTP/1.1 200 OK
Content-Type: text/html
Content-Security-Policy: frame-ancestors 'none'
X-Frame-Options: DENY

<html>
  <body>
    <button>Confirm Account Action</button>
  </body>
</html>

Fixed point: The browser blocks the page from being embedded in a frame.

05. Why Does It Matter?

An attacker may trick a user into performing actions they never intended, such as changing account settings, approving actions, or confirming transactions.
