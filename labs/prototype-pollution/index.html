Prototype Pollution

Explore how unsafe object merging can affect JavaScript prototypes.

About This Vulnerability

Prototype Pollution is a JavaScript vulnerability that occurs when untrusted input modifies an object's prototype through unsafe property merging.

This can cause unexpected properties to appear in objects that inherit from the affected prototype.

How Does It Work?

JavaScript objects can inherit properties from their prototypes. If an application merges untrusted input without proper checks, an attacker may introduce unexpected inherited properties.

In this lab, the behavior is safely simulated without modifying the browser's real Object.prototype.

Potential Impact

  • Unexpected properties may appear in JavaScript objects.
  • Application logic may behave incorrectly.
  • Security checks may be affected if they trust inherited properties.

Vulnerable Code

if (key === "_proto_") {
    Object.assign(target.prototype, value);
}

The application accepts special properties from untrusted input and copies them into the simulated prototype.

How to Prevent It

Validate untrusted input, reject dangerous keys, and use safer object-handling techniques when merging data.
