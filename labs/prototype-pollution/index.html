INTERACTIVE SECURITY LAB 03

Prototype Pollution

Learn how one unsafe merge can change the properties of every object in a JavaScript application.

01. What is Prototype Pollution?

Prototype Pollution happens when an application merges untrusted input into an object without checking the keys. The attacker can then change the prototype that other objects inherit from. Every object then receives properties the attacker chose.

OWASP: A08:2021 – Software and Data Integrity Failures

CWE: CWE-1321 – Improperly Controlled Modification of Object Prototype Attributes

02. The Vulnerable Code

A recursive merge function, used to apply user settings. 

function merge(target, source) {
  for (const key in source) {
    if (typeof source[key] === "object" && source[key] !== null) {
      target[key] = target[key] || {};
      merge(target[key], source[key]);
    } else {
      target[key] = source[key];
    }
  }
  return target;
}

merge(userSettings, JSON.parse(input));

Why it is vulnerable: The function follows any key it receives. With the key __proto__, target[key] is the shared prototype, so the merge writes into it.

04. Why Does It Matter?

A polluted prototype can switch on flags like isAdmin for every user, bypass checks, or crash the application.

Real incident: In 2019, CVE-2019-10744 was found in defaultsDeep of lodash, one of the most used npm libraries. A crafted constructor.prototype payload could add properties to all objects. It was rated 9.1 (critical).

05. The Fix

Skip the dangerous keys before following them. 

function merge(target, source) {
  for (const key in source) {
    if (key === "__proto__" || key === "constructor" || key === "prototype") continue;
    if (typeof source[key] === "object" && source[key] !== null) {
      target[key] = target[key] || {};
      merge(target[key], source[key]);
    } else {
      target[key] = source[key];
    }
  }
  return target;
}

Why it works: The merge never walks into the prototype, so the same payloads change nothing. Safer options: Object.create(null) objects or a Map.
